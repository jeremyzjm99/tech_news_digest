Infrastructure Hacker News 6/10

Since Linux 6.9, LUKS suspend stopped wiping disk-encryption keys from memory

A regression introduced in Linux kernel version 6.9 caused LUKS suspend to stop properly wiping disk-encryption keys from system memory, leaving sensitive cryptographic material potentially exposed during suspend states. This is a significant security vulnerability for systems relying on full-disk encryption, as keys remaining in memory could be extracted via cold-boot attacks or other memory forensics techniques. The issue has been identified and discussed in the community, highlighting the importance of regression testing for security-critical kernel features.
