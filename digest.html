An AI language model reportedly generated false information that nearly prompted a U.S. military operation, highlighting the real-world risks of deploying LLMs in high-stakes decision-making contexts. Tools Hacker News 7/10

Bend – A language that blocks AI mistakes via proof, on CPU and GPU

Bend is a new programming language designed to prevent AI-generated code errors by requiring formal mathematical proofs of correctness before code can run. It is built to execute on both CPUs and GPUs, making it suitable for high-performance and parallel computing workloads. The language aims to bring formal verification into mainstream development workflows, reducing bugs and increasing reliability in AI-assisted coding.
