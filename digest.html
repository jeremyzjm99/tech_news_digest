Tools VentureBeat AI 8/10

Claude Code costs up to $200 a month. Goose does the same thing for free.

Anthropic's Claude Code, a terminal-based AI coding agent, costs up to $200/month and has drawn developer backlash over opaque, token-based usage limits that some users exhaust in under 30 minutes. Goose, an open-source alternative built by Block (formerly Square), offers comparable autonomous coding capabilities at zero cost by running locally on a user's machine with support for any language model, including fully offline setups via Ollama. While Goose trades off some model quality and context window size compared to Claude's flagship models, it appeals to developers prioritizing cost, privacy, and flexibility.
