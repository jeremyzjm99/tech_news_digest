Training a 4B model to produce 81% faster query plans than Postgres

Researchers trained a 4-billion parameter language model to generate SQL query execution plans that are 81% faster than those produced by PostgreSQL's built-in query planner. The work demonstrates that small, fine-tuned LLMs can outperform traditional rule-based database optimizers on query planning tasks. This has practical implications for database performance without requiring changes to the underlying database engine.

Nvidia announces native GPU programming in Rust

Nvidia has announced support for native GPU programming in the Rust programming language, allowing developers to write GPU kernels and accelerated code directly in Rust without relying on C/C++ or CUDA wrappers. This move brings Rust's memory safety guarantees and modern developer ergonomics to GPU computing workflows. It represents a significant step toward broadening GPU programming beyond the traditional CUDA/C++ ecosystem.

Breaking the 1.58-bit Barrier for Ternary LLMs

Researchers have advanced ternary large language model (LLM) quantization by pushing beyond the theoretical 1.58-bit threshold, enabling models to represent weights using only three values (-1, 0, 1) more efficiently than before. This approach significantly reduces memory and computational requirements while maintaining competitive model performance. The work has implications for deploying powerful LLMs on resource-constrained hardware.
